Modelos ML integrados:
---------------------
1. Husky - Logistic Regression (clasificar seguridad)
2. ANYmal - Linear Regression (predecir ETA)  
3. PuzzleBot - K-Means (identificar zonas)
4. Coordinator - Ridge Regression (tiempo total)

Dónde se ejecutan en sim.py:
---------------------------
- Línea ~308: Husky ML activado
- Línea ~365: ANYmal ETA predicción
- Línea ~419: PuzzleBot zonas identificadas
- Línea ~519: Coordinator predicción final

Cómo usar:
----------
python3 sim.py

Verás salidas ML como:
[ML] Husky - Logistic Regression activado
[ML] ANYmal ETA: 38.5s (Linear Regression)
[ML] PuzzleBot 0 en zona: wait (K-Means)
[ML] Coordinator - Ridge Regression:
  Tiempo predicho: 92.1s
